# 室外测试安全 Checklist

## 测试前

- [ ] 场地已确认，无机动车、人群密集区、湿滑路面。
- [ ] 已获得指导教师或场地负责人许可。
- [ ] 紧急停止按钮可用，团队成员知道位置。
- [ ] 遥控器/急停手柄可用，备用电池已充满。
- [ ] `/cmd_vel` 限速已设置，默认不超过 0.5 m/s。
- [ ] GPS 天线位置正确，已确认 `/fix` 有有效解。
- [ ] 所有人员站在机器人后方或侧面，不在前进路径上。
- [ ] 已检查轮胎、螺丝、线缆和传感器固定。

## 测试中

- [ ] 低速起步，先短距离直线确认方向。
- [ ] 全程有至少一名观察员盯着机器人。
- [ ] 遇到异常立即急停，不等到自动保护。
- [ ] 不横穿马路，不进入 GPS 遮挡严重的建筑角落。

## 测试后

- [ ] 已停止所有运动指令。
- [ ] 已保存 bag、日志和截图。
- [ ] 已检查电池电压和充电状态。
- [ ] 已记录失败现象，便于后续分析。

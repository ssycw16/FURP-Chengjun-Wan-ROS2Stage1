## 遇到的问题与解决方案
1. **问题1**：执行`apt upgrade`系统全量更新时耗时极长，网速较慢。
   解决：选择挂机等待完成，也可使用`Ctrl+C`终止，仅执行轻量`apt update`，不影响ROS2基础使用。
2. **问题2**：使用旧launch文件名无法启动海龟窗口。
   解决：改用指令 `ros2 run turtlesim turtlesim_node` 直接运行节点，启动正常。
3. **问题3**：关闭终端后海龟图形窗口未同步关闭。
   解决：两个节点相互独立，单独关闭控制终端不影响仿真窗口，在仿真终端使用`Ctrl+C`即可正常关闭。

## 实验验证结果
